# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 声环境恢复记录

讲解团离场后的噪声恢复闭环在「声环境恢复队列」中处理：

- 每次巡测绑定样点、**声级峰值(dB)**、**团队人数**和测量时间。
- 峰值超过样点的**噪声限值**时自动建立观察单，样点转入**重点保护**。
- 同一样点未恢复前再次超限上报，只更新原单并累加超限次数，不另开单。
- 恢复需由**另一位巡测员**（非开单人）**连续两次**测得低于限值，且两次间隔**不少于 2 小时**；期间再超限会清零确认进度。
- 修订巡测声级或样点噪声限值后，按新值重放该样点全部巡测、重新判定未结束的观察单（可能撤销、补建或直接恢复），旧结论始终保留在观察单履历中。
- 队列按等待时长（开单或首次确认起算）排序，卡片显示处理人和还差几项确认。
