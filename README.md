# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 声环境恢复闭环

讲解团离开后，在「巡测记录」登记每次巡测时绑定**样点、峰值声级(dB)、团队人数**；样点档案中维护该样点的**声级限值**。

- **自动建单**：巡测峰值超过样点限值时自动建立声环境观察单；同一样点未恢复前再次超限上报，只更新原单并累加次数（更新峰值与团队明细），不另建新单。
- **重点保护**：观察期间样点自动置为「重点保护」，恢复闭环后回到观察前状态。
- **双确认恢复**：须由**另一位巡测员**（非首次上报人）登记复测，**连续两次**复测声级低于限值，且两次间隔**不少于 2 小时**，观察单才置为「已恢复」。期间任一次复测不合格、换人、间隔不足，或再次出现超限上报，确认进度清零重来；每次尝试均留痕。
- **按新值重判**：修订巡测声级或样点声级限值后，未结束的观察单按新值重判——达标则关闭恢复，不达标继续观察；旧确认结论若不再满足新限值会作废，全部历史结论保留在履历中不覆盖。
- **恢复队列**：「声环境恢复」页按等待时长（自最近一次超限上报）升序排列，展示处理人（首次上报人）、当前峰值/限值、上报次数，以及还差几项（两次合格复测、2 小时间隔、峰值达标）。
